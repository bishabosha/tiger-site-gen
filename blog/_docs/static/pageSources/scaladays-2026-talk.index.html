Reactor + Gears: direct-style async

lampepfl/gears

RPC: write request to server, wait for response

multiplatform API · (JVM, Native, Wasm)

ReactorFutures.run { r =>
  while buf.hasRemaining() do
    perform(r,
      r.ops.write(socket, buf))
  var running = true
  while running do
    buf.clear()
    perform(r, r.ops.read(socket, buf))
    running = buf.position() != 0
    if running then
      buf.flip()
      drainTo(buf, response)
}

run creates an event queue "reactor" r on the current thread, scheduling its argument.

Stage 1: loop to write to socket

perform registers the command to the reactor, and suspends the task. Reactor resumes it post-completion.

write creates a command, upon resume I/O was already performed.

Appears like blocking code: concurrency is abstracted.
